# 클론 코딩

첫 번째 값(`$1`)을 보고 어떤 작업인지 정해 줘.

- `page` → **화면 클론**
- `menu` → **리스트 클론**

받은 값 전체: $ARGUMENTS

---

## A. 화면 클론 (`page`)

아래 예시 이미지를 참고해서 똑같이 클론 코딩해 줘.

### 예시 이미지 (FewShot)

- 이미지 1: $2
- 이미지 2: $3

### 기준

- 이미지가 두 장이면 두 장 모두 참고해서 하나의 화면으로 만들어 줘. (한 장만 들어오면 그 한 장 기준으로)

---

## B. 리스트 클론 (`menu`)

예시 이미지에 있는 리스트를 클론 코딩하고, 리스트 내용은 받은 목록으로 채워 줘.

### 예시 이미지 (FewShot)

- 이미지: $2

### 리스트 목록

- 받은 값에서 앞의 두 값(`menu`, 이미지 경로)은 빼고, 나머지를 리스트 항목으로 써 줘.

### 기준

- 항목 디자인은 하나로 통일하고, 목록에 있는 개수만큼 반복해서 만들어 줘.
- 목록에 없는 항목은 임의로 추가하지 마.

---

## 공통 작업 기준

- 이미지에 보이는 레이아웃, 간격, 색상, 글자 크기, 정렬을 최대한 그대로 맞춰 줘.
- 이미지에 없는 기능이나 요소는 임의로 추가하지 마.
- Tailwind를 쓸 때는 크기를 `text-[12px]`, `h-[60px]`처럼 px 값으로 적어 줘. (`xs`, `xl` 같은 이름 토큰은 쓰지 마)
- 첫 번째 값이 `page`나 `menu`가 아니면 작업하지 말고 어떤 작업인지 물어봐.
